# 项目管理

Dozer 里的"项目"就是一个 git 仓库(或者一个会被自动 `git init` 的目录)。所有 agent 会话、验收记录、待办、目标都挂在项目上,而不是挂在某个 agent 上——换 agent 不丢历史,这是设计上的硬要求。

## 新建 / 添加项目

顶栏 "＋" 或首页项目列表底部的 "＋新增项目",会弹出一个原生的 macOS 打开面板,同时允许选目录或选文件(选目录 = 新建/添加项目)。

选中目录后,Dozer 自动跑一遍幂等的"脚手架"检查(见 [快速开始](getting-started.md#第一次打开创建或添加一个项目)):建 `.dozer/`、补 README、`git init`、扫描项目文档/agent 记忆文件。这个过程没有进度弹窗,除非你在项目面板手动点"修复/同步"重新触发它,那时才会看到一个带进度的模态框。

## 多项目标签

打开多个项目后,顶栏会为每个项目显示一个标签,可以拖拽调整顺序;标签太多挤不下时会自动收窄。每个标签上有个小圆点,颜色代表这个项目里活跃会话的最高优先级状态(等你输入的紧迫程度最高,其次运行中,再其次刚结束一轮,再其次空闲;还没收到过 hook 数据的会话显示灰色)——不用一个个点开就能扫一眼哪个项目在等你。

点标签切换项目,点最左侧 "Dozer" 回首页。

## 项目面板

左图标栏的 "Project" 面板显示:

- 项目名、当前 git 分支、是否有未提交改动(脏标记)。
- 累计验收次数(读 `dozerd` 里的验收记录库)。
- "虚拟链接"——自动发现的项目文档/agent 记忆类文件(比如 `AGENTS.md`、`README.md`)列表,点了直接在预览面板打开;你手动移除过的链接不会被重新扫出来。
- "修复/同步"按钮——重跑一遍脚手架步骤,带进度提示。
- 删除项目的入口。

## 文件树的 git 装饰

左图标栏的 "Files" 面板(文件树)会给每个文件按 git 状态上色/加标记(新增、修改、删除,已暂存/未暂存都能区分,忽略文件也有标记),目录会做"汇总上色"(子文件有改动,父目录跟着提示)。完整的 Files 面板功能(右键菜单、拖拽导入、内置搜索等)见 [面板参考](panels.md#files)。

## 删除项目

在项目面板里操作:从 `dozerd` 注销这个项目(不会删除你磁盘上的文件/git 仓库),可选再深一步"顺带清掉已摄取的对话缓存"。

## 首页的作用

首页(点顶栏 "Dozer")不属于任何单个项目,是一个总览:

- 左栏——所有项目列表(可搜索、分页),以及一个"最近"标签页(最近改动过的文件、最近的对话,点了直接跳进对应项目上下文)。
- 右栏——一个独立的、常驻的迷你浏览器,跟你打开哪个项目无关。

## 重启后恢复

关闭 Dozer 再打开,之前开着的项目标签会按 `open_projects.json` 里记的原样恢复;如果这个文件还不存在(比如第一次装),就落在最近使用过的那个项目上。终端会话本身由 `dozerd` 常驻持有,不受 app 重启影响,滚屏历史和可继续输入的状态都还在。
