# Dozer 用户手册

Dozer 是站在用户(甲方)一侧的、agent 中立的 AI 治理与验收层——一个 macOS 桌面应用。你在里面打开真实的 agent 终端(Claude Code、Codex、CodeBuddy……)干活,Dozer 负责让你随时能看清它们改了什么、方便地预览产物、以及决定这一轮交付收不收。

Dozer **不是** IDE、不是代码编辑器、不是 AI 聊天应用、不是终端模拟器,也不是又一个 agent——它不跟你的 agent 抢活干,只负责判断这一层。

## 核心心智模型

- **项目是资产,agent 是可更换的乙方。** 目标、验收标准、验收记录、对话历史都挂在项目上,不挂在某个 agent 上——今天用 Claude、明天换 Codex,历史不丢。
- **验收权不属于被验收方。** 通过/打回是你按的按钮,不是 agent 自己说"我做完了"就算数。
- **预览是为了让你少跳出 Dozer,不是为了让你替 agent 干活。** 能通过对话让 agent 改的,就不要自己在预览里手改。

## 一期范围说明

这份手册记录的是 Dozer 当前**实际实现**的行为,不是设计文档里的远期设想。如果你在别处的设计稿/spec 里看到手册里没有的功能(比如命令面板、图形化设置页、浅色主题),说明那是尚未落地的规划,不代表当前版本已经有。
