# 快捷键

Dozer 目前**没有命令面板**、**没有可自定义的快捷键配置**、也**没有应用内的快捷键帮助页**——这里这份表就是全部的应用级快捷键(不包括终端里正常的按键输入,比如方向键、Ctrl+字母控制码,那些照常透传给终端本身)。

| 快捷键 | 作用 |
|---|---|
| `Esc` | 按优先级关闭当前打开的浮层——依次检查:文件树搜索弹窗、任意右键/上下文菜单、agent 选择菜单、"添加项目"菜单、Todo 派发弹窗、Todo 日历弹窗、预览编辑浮层(关闭前会检查有没有未保存的改动) |
| `⌘C` / `Ctrl+C` | 复制当前选中内容(终端选区、webview 内容,或任何当前聚焦控件里选中的文本)到系统剪贴板 |
| `⌘V` / `Ctrl+V` | 把剪贴板内容粘贴到当前聚焦处(终端 PTY 或聚焦的原生文本框);如果剪贴板里是一张图片,会先写成临时 PNG 文件,粘贴的是**这个文件的路径**——这样 Claude 这类走文本输入的 CLI 也能把它当图片附件识别 |
| `Ctrl++` / `Ctrl+=` | 放大整个应用界面(不是网页缩放) |
| `Ctrl+-` | 缩小整个应用界面 |
| `Ctrl+1` | 重置缩放到 100% |

缩放级别会被记住(存在 `ui_scale.json`),下次打开还是你上次调的比例。

## 关于 ⌘K

一些早期设计文档提到过"⌘K 打开命令面板、预览会自动隐藏"这个设定——**这个功能目前没有实现**,顶栏曾经有一个纯视觉占位的搜索框,已经被移除,现在完全没有对应入口。如果你在别处的文档里看到这个说法,以本页为准:目前不存在。

## 其余按键都去哪了

方向键、Enter、Backspace、Tab、Ctrl+字母控制码、输入法组合输入等,要么直接交给当前聚焦的原生文本框(搜索框、地址栏、意见输入框——iced 自己处理),要么在没有任何东西抢占时,原样翻译成字节写进当前聚焦终端的 PTY。webview 内部也独立拦截了缩放和复制这几个按键,保证不管焦点在 webview 还是原生界面上,这几个快捷键手感一致。
