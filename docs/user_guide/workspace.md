# 工作区布局

Dozer 的界面分两种模式:**首页**(不属于任何项目)和**项目工作区**(每个打开的项目一份)。

## 顶栏

贯穿两种模式,固定在窗口最上方:

- 最左 "Dozer" 按钮——点它随时回首页。
- 一排项目标签——每个打开的项目一个标签,可拖拽重新排序,标签太多时会自动收窄;每个标签上有一个状态点,颜色反映这个项目里"优先级最高"的会话状态(等你输入 > 运行中 > 一轮刚结束 > 空闲 > 还没有 hook 数据时是灰色)。
- "＋"——添加项目(见 [项目管理](projects.md))。
- 右上角一个设置齿轮图标——**目前是纯装饰,没有接任何点击行为**,Dozer 还没有图形化设置面板(见 [配置与数据位置](configuration.md))。

顶栏本身也是窗口拖拽区——在标签之间的空白处按住鼠标可以拖动整个窗口。

## 首页

点顶栏 "Dozer" 进入。左栏是项目列表(可搜索,超过 5 个分页展开)和一个"最近"标签页(最近改动的文件/最近的对话,点了直接跳进对应项目);右侧是一个独立的、跟任何项目都无关的迷你浏览器,常驻在那里。

## 项目工作区:四栏

打开一个项目后,你会看到经典的四栏结构:

```
[左图标栏] [左侧面板]   [右侧面板] [右图标栏]
```

- **左/右图标栏**——各是一列固定宽度的面板图标,总共 11 种面板(Project/Todo/Files/GitLog/Database/Ssh/Web/Agent/Conversations/Usage/Acceptance)分挂在两条栏上,默认左栏偏"项目资产类"(文件树、git 记录、待办、数据库、SSH、浏览器),右栏偏"agent/治理类"(Agent 会话列表、历史对话、用量统计、验收)。图标可以在栏内拖拽重新排序,也可以直接拖到另一条栏——这个布局会持久化,下次打开还是你调整过的样子。
- **左/右侧面板**——每条图标栏当前选中的那一个面板,显示在紧挨着它的区域里。两侧面板之间有一条可拖拽的分隔线用来调整左右宽度比例,每个面板都可以单独折叠收起,也可以"最大化"到占满整个窗口(适合专心看一份 diff 或盯着终端)。

同一时间,一条图标栏只会显示它当前选中的那一个面板——比如文件树、git 记录、组件视图不会挤在一起,靠底部图标栏切换。

## 底部状态条(footbar)

窗口最下方一条常驻细条,显示系统资源实况:CPU/内存/磁盘占用、上下行网络吞吐、代理状态(`Proxy {地址}` 或 `Proxy OFF`)。这不是"全局应用状态栏"——Dozer 刻意不做那种东西,等真有值得放的重要信息再考虑加。

## 缩放

`⌘/Ctrl` + `+`/`-`/`1` 可以整体放大、缩小、重置 UI 缩放比例(不是浏览器网页缩放,是整个应用界面),缩放级别会被记住。详见 [快捷键](keybindings.md)。

## 窗口/面板状态是持久化的

- 全局窗口大小、图标栏布局、左右分栏比例 → 存在应用配置目录的 `layout.json`。
- 每个项目自己的面板尺寸/折叠状态 → `panel_layouts.json`,按项目区分。
- 上次退出时开着哪些项目标签 → `open_projects.json`,下次启动自动恢复(如果这个文件还不存在,就落在最近使用的那个项目上)。

具体路径见 [配置与数据位置](configuration.md)。
