# 面板参考

Dozer 一共有 10 种面板,挂在左右两条图标栏上(见 [工作区布局](workspace.md))。**Project**、**Agent**、**Conversations** 分别在 [项目管理](projects.md)、[Agent 会话](agents.md) 里单独讲过,本页覆盖剩下的七个。

## Files

项目文件树。

- 按 git 状态给文件上色/加标记(新增/修改/删除、暂存/未暂存、忽略文件),目录做汇总上色。
- 右键菜单:打开、复制路径、在 Finder 中显示、复制/粘贴、删除(带确认)、新建文件/文件夹、重命名。
- 支持从系统 Finder 直接拖拽文件/文件夹进树里。
- 可以直接在树里切换分支或跑 `git init`。
- 右键"搜索"会弹出一个独立的搜索框,基于 ripgrep 引擎在某个子目录或单个文件范围内做全文检索——是即时搜索,不是预建索引,也不保留搜索历史。

## Todo

读写项目根目录的 `.dozer/todo.md`(标准 `- [ ]`/`- [x]` checklist,纯文本、git 可追踪、agent 也能直接写这个文件)。

- 支持筛选、视图模式切换、拖拽调整任务顺序。
- 每个任务可以挂一个到期日期(自带日历选择器)。
- 支持就地富文本编辑单条任务,也有一个"Markdown"模式可以编辑整个文件的原始文本。
- **"派给现有会话"**——可以把一条待办任务直接派发给一个当前正在跑的 agent 终端会话,不用自己手动复制粘贴任务描述。

## Git Log

提交历史图。

- 用 `gleisbau` 库把提交图画在一个 iced Canvas 上(直线轨道+圆点风格,不是贝塞尔曲线的那种)。
- 点一个提交看详情 + diff。
- 分支列表、切换分支。
- 提交搜索。
- 一次最多拉 200 条提交,客户端每页 20 条分页——没有"从 git 继续往前加载更多"这个动作,超过 200 条的历史看不到最早的部分。

## Database

数据库连接与浏览面板。

- 支持 Postgres、MySQL、SQLite、MongoDB 四种驱动,连接信息可增删改查,带一键测试连接。
- 密码不会存进明文配置文件,存在 macOS 钥匙串里。
- 连上之后可以浏览 schema/表/字段树。
- 有一个"浏览表数据"标签页,支持 WHERE 过滤、排序、翻页。
- 有一个"原始 SQL"标签页,能直接写查询看结果。

深度操作(比如复杂的建模、迁移管理)不在 Dozer 里做——这是一个"够用的原生摘要+验收现场",不是要取代专门的数据库客户端。

## SSH

远程主机连接面板。

- 主机连接信息增删改查,支持密码或私钥认证。
- 标准的 SSH host key 校验流程——第一次连接一个未知主机会提示你确认指纹,同意后才会信任。
- 每个主机可以开一个内嵌的远程终端标签(跟本地终端体验一致)。
- 有一个 SFTP 文件浏览标签,左右两棵树(本地/远程),支持上传下载。

## Web(浏览器)

一个功能完整的内嵌迷你浏览器,和 [资产预览](preview.md) 里那个极简网页标签是**两个不同的东西**——这个面板才是真正的"浏览器",带:

- 多个 URL 标签、地址栏、前进后退、页面标题跟踪。
- 书签,分**全局**和**当前项目**两个作用域,持久化在 `dozerd` 里。

首页右侧那个常驻浏览器(见 [项目管理](projects.md#首页的作用))用的也是这套能力,只是不属于任何具体项目。

## Usage

当前项目下各 agent 的 token/工具调用用量统计,用 Canvas 画图表(环形图/柱状图),支持按 agent 筛选。这是少数几个**不经过 `dozerd`、直接读磁盘上的 transcript JSONL 文件**来算数据的面板之一。
