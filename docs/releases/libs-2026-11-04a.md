# libs-2026-11-04a

This library snapshot pins every bytehost consumer to v0.4.23 and includes the
shared settings integration and review fixes. It is a library snapshot, not an
application binary release; the application version follows remote main.

- Compose settings using the shared dialog controller, Git state and Git view.
- Handle native / GPU construction failures as retryable failures and release
  partially created resources. Opening settings again retries the same session.
- Dispatch input before handling an unconsumed Escape; preserve IME composition
  and cancel application / advanced-page confirmations before closing settings.
- Consume the shared account recovery DTO; include English and Chinese recovery
  strings without changing credential namespaces or persisted JSON formats.

The pre-push hook also drops the stale invocation of the shell-region comparison
script retired when shell styles moved directly to ByteUI (7fb7cc43). Shared
dependency and host boundary gates remain enforced.

Validation uses a separate Cargo home and no local path patches: workspace
all-targets check, a second locked/offline check, shared dependency guard,
settings tests, host dependency mutation gate, panel boundary, log scope,
resource parity and formatting. Native GUI / IME / multi-display acceptance
remains outstanding. See the Digger release report for exact logs and CI links.

Consumers must pin libs-2026-11-04a together with bytehost v0.4.23 and regenerate
their Cargo.lock without development overrides. byteui remains v0.5.2 and
bytegit remains v0.9.2; both are existing published tags.
